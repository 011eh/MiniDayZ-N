## 1. 经验获取（✅ 50158-50172）

被动经验：在 "Map" 场景、玩家存活（iv[15]>0）时，每 **10 秒** 按当前**地图层级 CurrentLevel** 加经验：

| CurrentLevel（地图群系层级） | 每 10s 经验 |
|------------------------------|-------------|
| 0（初始森林） | +1 |
| 1 | +2 |
| 2 | +3 |
| 3 | +3 |

- 经验存于全局 `expierence_points`。
- **UI 显示值 = expierence_points - 16**（t543/t596 文本，每 0.3s 刷新）。即内部从 16 起算，界面从 0 显示（首 16 点为偏移基线）。
- 另有击杀/拾取等事件加经验（散落各处，本类聚焦被动与消费）。

## 2. 天赋花费公式（perk_cost，✅ 28455）

每买一个天赋后重算下个天赋价格：
```
perk_cost = 216*(perks_learnt_count+1) + 100*perks_learnt_count - 16*perks_learnt_count
          = 216*(n+1) + 84*n        （n = 已学天赋数 perks_learnt_count）
          = 300*n + 216
```
| 第几个天赋 (n买之前已学) | perk_cost（内部值） | 实际所需(显示) = cost-16 ? |
|------|------|------|
| 第1个 (n=0) | 216 | — |
| 第2个 (n=1) | 516 | — |
| 第3个 (n=2) | 816 | — |
| 第4个 (n=3) | 1116 | — |
| 第k个 (n=k-1) | 300(k-1)+216 | 线性 +300/个 |

购买条件：`expierence_points ≥ perk_cost`，扣经验、`perks_learnt_count += 1`、播 "MD_Perk_1" 音。

> 注：经验显示偏移 -16，perk_cost 公式内含 -16*n，两者共同构成 16 基线对齐。
