## 1. 时间推进（✅ 49417-49435）

每 **1.5 秒**（`Every(1.5)`）：
```
Timer_ALL += 1                               // 1 个 Timer_ALL = 游戏内 1 分钟
Timer_Hours   = floor(Timer_ALL / 60)        // 小时
Timer_Minutes = Timer_ALL - Timer_Hours*60   // 分钟
```
- **一天 = 1440 分钟**（24 小时）。`Timer_ALL > 1440` 时：`Day_survived += 1`，`Timer_ALL = 0`（新的一天）。
- 现实换算：1 游戏分钟 = 1.5 现实秒 → **1 游戏日 = 1440×1.5 = 2160 现实秒 = 36 分钟**。
- 时间字符串补零：Timer_Hours_Z / Timer_Minutes_Z（<10 补 "0"）。
- `Timer_ALL = 360`（即 06:00）时弹「第 N 天」标签 `Day_show_label`。

### 天数里程碑（✅）
- `Day_survived = 8` 且 SEED_RUN=0 → 解锁角色 11（`unlock_char_11`，49434-49436）。
- `Stats_time_lived` 达 2160 / 4320 / 6640（≈1/2/3 天的累计存活秒）→ 成就计数 t150.iv[2]+1，Check_ach_unlocks（49374-49392）。

## 2. 昼夜判定（Day&Night，✅ 49404-49435）

按 `Timer_Hours`：
- **0–5 时 = 夜晚**：`Day_mode = 0`，显示 night 图层，夜幕 t231 不透明度 100，播夜环境音（CurrentLevel≥2 用 "night_loop"，否则雪地夜 "MD_Winter_night_amb"），启用 night_force_texture 组。
- **6–23 时 = 白天**：`Day_mode = 1`，隐藏 night 图层，t231 不透明度 0，播日环境音（CurrentLevel≥2 "ambient"，否则雪地日 "MD_winter_amb"）。
- 地堡内（inBunker=1）不切换昼夜光照。
- 黎明/黄昏过渡：0 时和 5 时按 `abs(分钟)*1.69 - Night_light_addition` 渐变夜幕不透明度（49373-49377）。

> Day_mode 直接进入体温公式：夜晚额外受 Night_cold（见 玩家状态衰减与体温.md §5）。

## 3. 降雨/暴风雪（Rain，✅ 49439-49494）

### 触发周期
- 主时钟启动时 `StartTimer(Rain_speed, 循环, "Rain")`（1263）。**Rain_speed = 360**（data.js 初值）→ 每 **360 秒**（6 现实分钟）做一次天气判定。
- `OnTimer("Rain")` 且 `rains_level > 0` 时：
  - 若当前 Rain=1（正在下）→ 停雨：Rain=0，停雨声，淡出雨幕 t663。
  - 若当前 Rain=0 且不在地堡（inBunker≠1）→ `choose(1,2,3,4) = 1`（**1/4 概率**）起雨：
    - `Rain = 1`，创建雨幕 t663，帧 = (rains_level==1 ? 0 : 1)。
    - 音效：rains_level==1 → "rain_loop"(+屋顶"rainroof")；rains_level==2 → "blizzard"（暴风雪，无屋顶音）。
    - 玩家在屋檐 t337 下时，暂停 rain_loop、播 rain_roof（室内听屋顶雨声）。

### 雨幕粒子（每 0.4 秒生成一批）
| rains_level | 类型 | 粒子速度 | 缩放/帧 | 落角 |
|-------------|------|----------|---------|------|
| 1（普通雨） | t266 (帧0) ×4 + t368 雨滴 | random(700,1500) | scale choose(1,2) | random(80,110)° |
| 2（暴风雪） | t266 (帧1) ×2 + t482 雪 | random(50,150) | scale choose(1,2,3) | random(80,110)° |

> 普通雨粒子快（700-1500，斜落如雨）；暴风雪粒子慢（50-150，飘落如雪）。

### rains_level 等级（✅）
- 初值 `rains_level = 0`（data.js）→ 完全无雨。
- 地图/生物群系初始化时按场景设定：森林/初始场景 = 1（8674、9092），冬季/雪地群系 = 2（8872、8978）。
- **存活 ≥ 5000 秒**（Stats_time_lived≥5000）且 SEED_morezeds=0、TriggerOnce → `rains_level = 2`（50209-50212，难度递进：后期普遍升级为暴风雪天气）。同时按难度提升 Zed_per_base（Novice/Regular=5、Veteran=6）。

> 体温公式中下雨（Rain=1）且不在屋檐下时额外受 Rain_cold（见 玩家状态衰减与体温.md §5）。
