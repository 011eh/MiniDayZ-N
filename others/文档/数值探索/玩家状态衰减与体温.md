## 1. 玩家状态实例变量（iv）

| iv | 含义 | 量程 | 备注 |
|----|------|------|------|

## 2. 每 5 秒结算（States 组主循环，✅ 14516-14583）

每 5 秒（`Every(5)`）执行：

```
iv[14](水分)  -= Thirsty_current
iv[13](饥饿)  -= Starving_current
iv[16](体温)  += Player_temperature / 2        // 体温条 += 即时体温/2
若 perk_camel:   iv[14] += 0.3                  // 骆驼天赋，每结算补水
若 perk_hamster: iv[13] += 0.3                  // 仓鼠天赋，每结算补食
```

随后逐项归零判定：
- iv[13] < 0 → 置 0，**iv[15](生命) -= 1**，Stats_blood_lost +1，若生命≤0 死因="Hunger"
- iv[14] < 0 → 置 0，**iv[15] -= 1**，Stats_blood_lost +1，若生命≤0 死因="Thirst"
- iv[16] < 0 → 置 0，**iv[15] -= 0.25**，若生命≤0 死因="Cold"

**自然回血（Regeneration）**：当 iv[14]≥50 且 iv[13]≥50 且 iv[16]≥50 且 iv[22]=0（不出血）且 iv[34]=0（不感染）时：
```
iv[15] += Regeneration_current
若 iv[32]=1(维生素):       iv[15] += Regeneration_current   // 再加一次 = 翻倍
若 perk_regen 且 iv[15]<50: iv[15] += Regeneration_current   // 低血时再加一次
```
即维生素和「低血+regen天赋」可叠加，最多 3×Regeneration_current/5s。

**感染加重**：iv[34]=1（感染）时每 5s 额外 `iv[14]-=1, iv[13]-=1`。

## 3. 出血（Bleeding，✅）

- **触发**：受到攻击/掉血事件设 iv[22]=1，并启动 `Bleed` 计时器。
- **持续掉血**：iv[22]=1 时每 **1 秒** 执行（14671-14688）：
  ```
  iv[15] -= (perk_metabolism==1 ? 0.25 : 0.5)   // 新陈代谢天赋使出血掉血减半
  ```
  并在地面 Spawn 血滴 t242；若生命≤0 死因="Bleed"。
- **酸液池**（t904，14690-14693）：出血状态下每 0.5s 重叠 t904 则 iv[15]-=25（即时大伤害）。
- **停止**：`Bleed` 计时器到点 → iv[22]=0（14920-14921）。使用绷带等也会清 iv[22]、StopTimer("Bleed")（17715-17727、17860-17869）。

> 计时器 `Bleed` 时长 = **60 秒**（✅ 事件 48713 等 `StartTimer(60, 不循环, "Bleed")` 明文确认）。即一次出血最多持续 60s，期间每 1s 掉血；60s 到点自动止血（iv[22]=0），用绷带/破布可提前止血。

## 4. 装备保暖换算（Update_Stats 函数，✅ 14797-14820）

每次 `Update_Stats` 重算装备保暖：对玩家穿戴的头(iv[18])/上衣(iv[8])/裤(iv[20]) 对应衣物对象 t909：
```
t909.iv[8] = (t909.iv[9] / 100) * t909.iv[6]     // 当前保暖 = (满保暖/100) × 耐久
iv[28] = 头部 t909.iv[8]
iv[27] = 上衣 t909.iv[8]
iv[29] = 裤子 t909.iv[8]
```
- **t909.iv[9] = 该件衣物的满保暖值**（衣物对象类型默认值，混淆，◻️ 见 物品类型与数值.md 第5章；事件 14805 等只读不赋）
- **t909.iv[6] = 衣物当前耐久**（0-100，出生/拾取时设 100，受击时按 round(random(10,15)) 等扣减——见 生物数值.md §6.4）

即衣物破损（iv[6]↓）会按比例降低保暖，满耐久(100)时保暖=满保暖值 iv[9]。三件保暖之和用于体温公式（§5）。
> 注：此前曾把 iv[6]/iv[9] 含义写反，已据 生物数值.md §6.4（受击扣 iv[6] 耐久）+ Update_Stats 公式订正。

## 5. 即时体温公式 Player_temperature（✅ 14802-14848）

每次 `Update_Stats` 先 `Player_temperature = 0`，再逐项加减：

| 条件 | 体温变化 | 对象 |
|------|----------|------|
| 夜晚 (Day_mode=0) | `- Night_cold` | — |
| 下雨 (Rain=1) 且 玩家不在屋檐 t337 下 | `- Rain_cold` | t184 不与 t337 重叠 |
| 站在篝火 t275 上 | `+ 15` | t275 |
| perk_snowborn 天赋 | `+ 2` | — |
| 站在热源 t337 内（室内/暖区） | `+ t337.iv[0]`；若 perk_sweethome 再 `+ t337.iv[0]/2` | t337 |
| 在地堡 inBunker=1 | `+ 5` | — |
| 在可驾驶载具内（iv[44]，载具 t946 有油且未损毁） | `+ 4` | t946 |
| **基础日寒（始终）** | `- (Day_cold - (iv[28]+iv[27]+iv[29]))` | 衣物保暖抵消日寒 |

> 即：体温受「日寒 Day_cold」恒定下拉，衣物三件保暖之和抵消之；夜/雨另加寒；篝火/室内/载具/天赋加暖。

**结算到体温条**：体温条 iv[16] += Player_temperature/2（§2）。
- Player_temperature>0 且 iv[16]>0：显示「+ceil()」回暖提示；若 **Player_temperature>100 → 中暑**：iv[15]=5、iv[22]=1（暴血+出血）（14855-14861）。
- Player_temperature<0：显示「floor()」受寒提示。

### 难度寒冷常量（✅ 1391-1428）

| 难度 | Night_cold | Rain_cold | Day_cold |
|------|-----------|-----------|----------|
| Novice（新手） | 1 | 1 | 6 |
| Regular（普通） | 2 | 2 | 7 |
| Veteran（老兵） | 3 | 3 | 8 |

## 6. 难度衰减速率常量（✅ data.js 全局变量初值）

States 组按难度把 `*_current` 设为对应难度常量（1395-1425）。这些 `Veteran_starving` 等在事件表声明处为 0（解析默认），**真实初值取自 data.js 全局变量定义**：

| 变量 (每5s作用一次) | Novice | Regular | Veteran |
|----------|--------|---------|---------|
| `*_starving`（饥饿衰减/5s） | **0.75** | **1.1** | **1.4** |
| `*_thirsty`（水分衰减/5s） | **0.75** | **1.1** | **1.4** |
| `*_regeneration`（自然回血/5s） | **2** | **1.75** | **1.5** |
| `*_weathercold` | 0 | 0 | 0（未使用，寒冷走体温公式） |

来源：✅ `data.js` 全局变量定义段（`Novice_starving",0,0.75`、`Veteran_starving",0,1.4` 等）。

> 折算：Veteran 饥饿/水分约 1.4/5s ≈ 16.8/分钟，满 100 约 6 分钟见底；Novice 0.75/5s ≈ 9/分钟。回血 Novice 最快（2/5s）、Veteran 最慢（1.5/5s），与难度递增一致。

附：难度同时设定的相关伤害常量（1383-1426）：

| 难度 | Zed_dmg | Zed_army_dmg | Wolf_dmg | Difficulty_damage_reducer |
|------|---------|--------------|----------|---------------------------|
| Novice | 6 | 9 | 6 | 7 |
| Regular | 9 | 13 | 8 | 5 |
| Veteran | 10 | 15 | 10 | 3 |

来源：✅ 1383-1432。Difficulty_damage_reducer 越大玩家受伤越少（玩家承伤减算因子）。

## 7. 感染（Infection）机制（✅）

- **触发**：体温条 iv[16]≤0 时，`random(50) > 28`（即 22/50 = **44%**）→ iv[34]=1（感染），显示 t433（14583-14586）。
  - 另有酸/僵尸源：`choose(0,1)=1`（50%）也可致 iv[34]=1（14910-14913，死因="Acid"）。
- **效果**：iv[34]=1 时每 5s 额外 iv[14]-=1、iv[13]-=1（§2），且禁止自然回血。
- **自愈**：iv[14]≥80 且 iv[13]≥80 且 iv[16]≥80 且 iv[22]=0 时，`choose(1,2)=1`（50%）→ iv[34]=0（14592-14596）。
- 维生素 iv[32]=1 时免感染（参与回血条件，间接）。药物（四环素）清感染走单独逻辑（物品文档）。

## 8. 死亡判定（Death_log_reason，✅）

iv[15]≤0 触发死亡：记录 `Death_log_reason`，清存档 `gamesav_v4=0`，销毁玩家 t172/t184，调用 Dead_screen（14655-14665）。死因字符串：`Hunger / Thirst / Cold / Bleed / Acid`（及战斗死亡在别处）。
Casual 模式（SEED_playcasual=1）下生命≤0 会被强制拉回 1（14510-14514，不死）。
