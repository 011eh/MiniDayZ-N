## 1. 建造部署模式（Building mode，✅ 28540-28755）

进入建造：`Building_mode` 函数 → 创建预览幽灵 t566（在玩家右侧 +50），按 `Param(0)` 设帧（决定部署物类型），Building_mode=1。
玩家拖动 t566 选位，每 0.1s 检测放置合法性。

### 放置合法性（Building_deploy_avalible，✅ 28552-28580）
合法（绿色，可放）需**同时满足**：
- 距玩家 **distance(t566, 玩家) > 100**（不能贴脸放）；
- **不重叠** 任意：t927 / t336（障碍碰撞体）/ t339 / t199 / t202 /（部署帐篷时还含 t337 暖区）；
- **不在地堡**（inBunker=0）。
非法时预览红色、半透明 50%，禁止确认；合法时绿色、不透明 100%。

## 2. 种植 / 播种（✅ 17935-18010）

用种子物品（背包使用，`item_activate` Param(0)=种子ID）播种：

### 播种条件（全部满足，✅）
- 不在车内（iv[44] 未置位）；
- 玩家重叠耕地图层 **t945**，且当前 tile = **6**（可耕土壤瓦片）；
- 玩家场景 iv[4] ∈ {2,10,11}（特定可种植地图层级/群系）；
- 不重叠 t411、不重叠 t337（暖区/帐篷），不在地堡（inBunker=0）。

满足后：玩家 iv[21]=1，播 "planting_seeds" 音，**等待 5s**，在脚下生成对应作物对象，启动 `grow` 计时器（每 **20 秒** 一 tick），种子数量 -20（栈计数，Param(1)-20，到 0 用尽）。每次播种 +1 成就计数 t153.iv[2]。

## 3. 作物生长（Gardening，✅ 22845-22861）

作物对象（t940 为通用引用，实际 t554/t552/… 共享同一 grow 逻辑）每次 `grow` 计时（**20s/tick**）且未成熟（iv[1] 未置位）：
```
iv[0](生长进度) += 20
帧 = floor(iv[0] / 240)        // 每 240 进度换一帧（共 0~6 帧生长阶段）
```
- **枯萎判定**：iv[0] = 540 时，`choose(1,2,3,4)=1`（**25%**）且 `perk_agronom=0`（无农艺天赋）→ 设帧 7（枯萎）、停 grow、iv[3]=1（枯死标志）、淡出。
  - 即每株作物在进度 540 节点有 25% 枯萎风险；**农艺天赋 perk_agronom 使作物永不枯萎**。
- **成熟**：iv[0] ≥ **1440** → 设帧 6（成熟）、停 grow、iv[1]=1（成熟可收）。

### 生长时间换算（✅）
- 每 tick +20，20s/tick → 满 1440 需 72 tick = **72×20 = 1440 秒 ≈ 24 现实分钟** 成熟。
- 枯萎检查点 iv[0]=540 → 27 tick = 540 秒 ≈ 9 分钟时判定一次枯萎。
- 生长帧阶段：floor(进度/240)，0→0,240→1,...1440→6（共 7 阶段视觉）。
