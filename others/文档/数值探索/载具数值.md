## 1. 载具实例变量（iv，✅）

| iv | 含义 | 备注 |
|----|------|------|
| iv[0] | 车型 | **1 = UAZ**，**2 = Volga** |
| iv[1] | 当前 HP | 撞击/碰撞扣减 |
| iv[2] | 最大 HP | UI 血条高 = 70/iv[2]×iv[1] |
| iv[3] | 当前油量 | 行驶每 tick 消耗 |
| iv[4] | 最大油量 | UI 油条高 = 70/iv[4]×iv[3] |
| iv[5] | 损毁标志 | 0/1，体温公式要求 iv[5] 未置位才提供 +4 暖 |
| iv[45]→玩家 | （玩家侧）iv[45] = 当前驾驶载具 UID | iv[44]=在车标志 |

玩家在车内（iv[44]）且载具有油（iv[3]>0）且未损毁（iv[5]=0）→ 体温 +4（见 玩家状态衰减与体温.md §5）。

## 2. 车型驾驶参数（✅ 23420-23480）

驾驶时按 iv[0] 设置 Car 行为参数（仅油量 iv[3]>0 时可加速）：

| 车型 (iv[0]) | 最大速度 MaxSpeed | 加速 Accel | 减速 Decel | 转向 SteerSpeed | 漂移恢复 DriftRecover | 行驶油耗 /tick |
|--------------|-------------------|-----------|-----------|-----------------|----------------------|----------------|
| **1 = UAZ** | 225 | 250 | 1000 | 150 | 125 | **-0.05** |
| **2 = Volga** | 275 | 250 | 1000 | 125 | — | **-0.07** |

- 油尽（iv[3]≤0）：Accel 设 0、Decel 大（2000/250），即**熄火滑行**；停引擎音、播 `car_engine_stop_uaz/volga`、尾气粒子降率（23453-23533）。Volga 转向降到 200、UAZ 同。
- Volga 速度更高（275 vs 225）但油耗更大（0.07 vs 0.05），转向更钝（125 vs 150）。
- 倒车/急转时附加减速：速度>75/100 且 <-75 时 `Speed -= 125`（或 -50），模拟撞击/急停（23300-23380）。

> 油耗 tick 频率由 Car 行为的 Every-tick 驱动（每帧），非固定秒；0.05/0.07 是每帧扣减量。

## 3. 碰撞伤害（Vehicle collisions，✅ 22933-23070）

载具撞**可摧毁障碍**且 `Car 速度 > 50` 时：
- `iv[1](HP) -= 15`，摧毁障碍（围栏 t310/木桩 t305/t306/t560 等），生成碎片粒子 t809/t814/t815/t818，播 `Fence_destroy` / `car_crash_1~3` 音效。
- 撞硬地物 t910 / t724：`iv[1] -= t910.iv[0]`（该物体自带的伤害值），播 `hard_ground` 音。
- 撞击后刷新驾驶者视角血条：t463 高度 = 70/iv[2]×iv[1]。

> 即**每次有效撞击固定 -15 HP**（普通障碍），硬物按其 iv[0] 伤害。撞击门槛速度 = 50。

---

## 4. 损毁与重生（✅ 23055-23075）

`iv[1](HP) ≤ 0` → 载具爆炸：
- 播 `car_explode`，生成火光/烟雾 t819、碎片 t820、掉落物 t821、销毁动画 t252。
- **重生计时器 = 600 秒**：UAZ→`Uaz_respawn`，Volga→`Volga_respawn`（StartTimer 600s）。即载具被毁后 10 分钟在原点/池中重生。

---

## 5. 加油 / 油料来源（✅）

- 载具上的油桶 loot（t806/t812 等车旁容器）初始油量随机：
  - `SetInstanceVar(iv[3], choose(0, 50))`（23621/23639）—— 大油桶 0 或 50。
  - `SetInstanceVar(iv[3], choose(0, 25))`（23661/23679）—— 小油桶 0 或 25。
- 玩家用 **Gasoline（物品 ID 53）** 给载具加油（具体每次加注量在油料使用逻辑，本组未含，归 合成/使用 文档；此处确认油来源物品为 53）。
