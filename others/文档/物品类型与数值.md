# Mini DAYZ 物品类型与数值设计

> 原始游戏：**Mini DAYZ 1.4.1**（Bohemia Interactive，Construct 2 工程）
> 本文档整理原始游戏全部物品的**类型分类**、**数值字段**与**具体数值**。

---

## 0. 数据来源与提取说明

数值取自原始 `original_docs/data.js`（主事件表 `Game_events`）解码后的明文逻辑。按提取确定性分两档：

| 标记 | 含义 |
|------|------|
| ✅ | 直接从事件表明文逻辑解码确认，确定 |
| ◻️ 待核实 | 该数值在 `data.js` 中以**混淆的实例变量默认值**存储（见 `objects/object_*.json` 的 `[3]` 哈希数组），未能明文解码；当前数值来自实机/社区资料，待进一步核实 |

**原始游戏中物品数值的两种存储方式：**

1. **消耗品效果**（食物/饮料/医疗）、**武器散布**、**掉落表** —— 以明文写在事件表里，可解码确认 ✅。
2. **武器伤害 / 弹匣 / 弹药类型**、**衣物护甲 / 保暖 / 容量** —— 存为各物品对象类型的实例变量默认值，在 `data.js` 中是混淆的哈希大整数，无法明文解码（标 ◻️ 待核实）。

### 已落盘的解析数据

- `datajs_export/game_events.decoded.txt` —— 主事件表 `Game_events` 可读伪代码
- `datajs_export/parsed/consumables.json` —— ✅ 消耗品效果表
- `datajs_export/parsed/weapon_dispersion.json` —— ✅ 武器散布表
- `datajs_export/parsed/item_names.json` —— 物品 ID→英文名
- `handler/extract_item_stats.py` —— 解析脚本

## 6. 武器

### 6.0 枪械数值字段全集与开火模型（✅ 机制确认）

枪械的数值设计**不止伤害/弹匣**，核心是一套「后坐力 / 散布动态模型」+ 武器与子弹的多个实例变量。

#### A. 武器实例变量字段（`t909` = 手中枪械）

| 字段 | 含义 | 提取状态 |
|------|------|------|
| `iv[0]` | 发射就绪标志（=1 可发射；半自动武器射击后置 0，松扳机复位） | ✅ 机制 |
| `iv[1]` | **武器内部索引**（决定弹道对象 / 音效 / 散布表） | ✅ |
| `iv[2]` | 状态锁（=0 可发射；上膛/卡壳=1） | ✅ 机制 |
| `iv[3]` | 当前弹匣余弹（每发 −1） | ✅ 机制 |
| `iv[4]` | 射击循环延迟 `Reloading_time`（半自动/栓动节奏） | ◻️ 默认值混淆 |
| `iv[5]` | 关联弹药/状态 | — |
| `iv[6]` | **耐久度**（每发磨损，按武器 0.3 / 0.4 / 0.5 / 0.6 / 0.8 / 1.0） | ✅ |
| `iv[11]` | 箭矢类型（弓弩：1/2） | ✅ |
| `iv[16]` | 瞄准镜槽（见 6.4） | ✅ |
| `iv[17]` | 枪口槽（消音器/扼流圈，见 6.4） | ✅ |
| `iv[18]` | 弹带槽（见 6.4） | ✅ |

#### B. 子弹实例变量字段

| 字段 | 含义 | 提取状态 |
|------|------|------|
| `iv[0]` | **基础伤害**，实际伤害 = `round(基础 ± 基础/4)` = **±25%**（例：Mosin 基础 90 → 67–113） | ◻️ 默认值混淆 |
| `iv[1]` | 射手 UID | ✅ |
| `iv[8]` | 精准射击标志：当散布降到最小（完全静止稳定）时置位 → 命中加成 | ✅ 机制 |
| `iv[9]` | **穿透**（基础 + 瞄准镜加成，见 6.4） | ✅ |
| Bullet 行为 | 飞行速度（弹速） | ◻️ 默认值混淆 |

#### C. 后坐力 / 散布模型（✅ 核心，源自 `Aiming` 组，每 0.1s 更新）

当前散布角 `dispersion_angle` 在 `[base_spread, max_spread]` 区间内动态变化：

- **静止不动**：每 tick `− cooldown_step`（精度恢复），下限 `base_spread`
- **移动中**：每 tick `+ run_penalty`，上限 `max_spread`
- **每开一枪**：`+ spread_per_shot`（后坐跳动），上限 `max_spread`
- **实际弹道角** = 瞄准角 `± random(dispersion_angle)`
- 准星 UI 按 `dispersion_angle / max_spread` 比例分 **5 档**张合显示
- 散布恢复到 `base_spread`（完全稳定）时，子弹获**精准标志** `iv[8]`

> 这 5 个参数（`base / max / per-shot / cooldown / run-penalty`）即用户所指的「后坐力/子弹散布」设计，**全部明文可提取**，按武器内部索引见 6.1。

#### D. 射速两类

- **全自动**（突击步枪/冲锋枪）：持续 `Every(0.07~0.13)` 触发 → 约 **460–850 RPM**
- **半自动 / 栓动**（手枪/狙击/霰弹）：按扳机 + `Wait(iv[4])` 循环延迟
- **霰弹枪**（IZH-43 / Remington / Saiga）：单次扳机生成**多发弹丸**，各自带随机散布
